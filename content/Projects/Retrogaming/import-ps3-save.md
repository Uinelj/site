---
title: Importing PS3 saves into RPCS3
tags: [gaming, retro]
---

1. Export your save from your PS3 (under games in the XMB, go to saves, export, export to USB).
2. Put them in the proper location on RPCS3 (manage -> save data, open a random one, go up one level, put the folder here)
3. Download and install apollo save tool on RPCS3 (go on github to get the pkg, drag n drop it into RPCS3 window)
4. Open Apollo save tool, open HDD saves, open your save and use "export decrypted save" or smth like that on all files that are available there
5. Open the location where those files are (apollo will tell you), overwrite the save files from step 2
6. Launch the game :)
